Citadel

Enterprise Browser Security for the Rest of Us

Citadel is an open-source browser agent that helps CISOs and CIOs secure their organization by enforcing IT policy, detecting malware and shadow IT, and enabling rapid incident response—all without compromising user privacy.

In today's landscape, the browser is the operating system. Traditional endpoint management solutions don't manage browsers effectively, and browser security solutions that do require expensive per-seat licenses, and often can't handle BYOD or contractor devices. Citadel changes this.

🛡️ Enforce Policy

Password quality, MFA requirements, device compliance, web filtering, and session duration limits—all managed from one agent.

🔍 Detect Threats

Malware downloads, blacklisted sites, encryption issues, dangerous browser extensions, and security violations detected in real-time.

📊 Manage Licenses

Track application usage and identify shadow IT or unused licenses without invasive monitoring of personal browsing.

🥷 Privacy Respecting

Only tracks authenticated applications, hashes URLs for forensics, and keeps data local. Designed for GDPR compliance.

🔌 Integrates Easily

Works with any SIEM/XDR that ingests syslog. Pre-integrated with Wazuh. No central server required.

🌐 Cross-Browser

Supports Chrome, Firefox, Edge, Brave, Opera, Arc, Atlas (OpenAI) and Comet (Perplexity). Works on macOS and Windows endpoints.

Device Security Controls

Citadel includes comprehensive device posture checks that verify your endpoints meet security standards. These controls ensure disk encryption is enabled, systems are updated, firewalls are active, and sensitive data is properly protected.
